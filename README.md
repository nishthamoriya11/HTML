# HTML Projects

Welcome to my HTML Projects repository. This repository contains practice projects created while learning the fundamentals of web development using HTML.

## About the Repository

The purpose of this repository is to strengthen my understanding of HTML elements, webpage structure, navigation, images, hyperlinks, tables, and forms through practical projects.

## Projects

### 1. Personal Portfolio Website

A personal portfolio webpage that introduces me and presents my technical skills, projects, education, and contact information.

**Features:**
- Personal introduction and About Me section
- Technical skills with images
- Project links
- Education details
- Contact information and LinkedIn link

### 2. Bicycle Website

A bicycle shopping webpage inspired by Pure Cycles, created to practise organising product and category information using HTML.

**Features:**
- Navigation menu
- Featured bicycle products and prices
- Shop by Category section
- Promotional images and video
- Footer with useful links and newsletter form

## Technologies Used

- HTML5 — webpage structure and content
- Visual Studio Code — code editor
- Git — version control
- GitHub — repository hosting

## Learning Outcomes

- Understanding basic HTML structure and elements
- Creating tables, headings, paragraphs, and lists
- Adding images and hyperlinks
- Building navigation links between webpage sections
- Creating forms and embedding external content
- Managing projects using Git and GitHub
